逃离未来城市Escape the Future City

世界观 / 核心循环SETTING / CORE LOOP
游戏概念GAME PREMISE

在系统追猎中保持前进Keep moving under system pursuit

Pulse Runner 是一款 2D 横向跑酷游戏。玩家操控一台苏醒的机器人，在未来世界中摆脱系统的控制与追捕。平台、敌人和收集物由随机流持续生成，操作重点是读懂前方威胁并选择合适动作。Pulse Runner is a 2D side-scrolling endless runner. Players control an awakened robot escaping a futuristic system and its pursuit. Platforms, enemies and pickups are generated from a random stream, so play centers on reading upcoming threats and choosing the right move.

THREAT 01

飞船Spaceship

出现在屏幕右上方并向玩家发射子弹。多种弹道要求玩家判断时机，以跳跃或滑行躲避。Hovers in the upper-right and fires along varied trajectories, asking the player to time jumps and slides.

THREAT 02

尖刺球Spiked Ball

在平台预设位置出现并上下移动；与平台绑定，避免单独生成时卡进平台，阻断路线。Appears at prepared points and moves vertically. Binding it to a platform prevents spawn collisions from blocking the route.

PICKUPS

收集物Collectibles

金币增加分数，护盾提供碰撞保护，冲刺道具赋予短时冲刺能力。Coins add score, shields protect against collisions, and dash pickups grant a burst of speed.

03

对象复用与组合Reuse & Composition

性能 / 可维护性PERFORMANCE / MAINTAINABILITY

让不断生成的赛道依靠复用与对象关系运转，减少反复创建、销毁和逐个检查。The endless route runs through reuse and clear object relationships, reducing repeated creation, destruction and one-by-one checks.

01 / OBJECT POOL

平台循环回收Recycle platform segments

启动时预生成平台与常用对象，将暂时离场的平台移到视野前方复用，避免奔跑过程中持续实例化新对象。Platforms and recurring objects are prepared at startup. Segments leaving view are repositioned ahead for reuse instead of constantly instantiating replacements.

02 / PROJECTILE RESET

子弹离场后重置Reset off-screen bullets

飞船子弹离开屏幕后回到飞船位置，再沿新随机弹道发射，避免不断累积子弹对象。Once a bullet leaves the screen, it returns to the ship and is fired along a new random path, preventing projectile buildup.

03 / COMPOSITE RELATION

平台携带关联物件Platforms carry attached objects

尖刺球与收集物跟随所在平台移动。平台换位时无需逐个查找对象、确认状态并更新坐标。Spiked balls and pickups move with their platform, removing the need to locate, validate and reposition each item separately.

碰撞判定集中处理SHARED COLLISION LOGIC

玩家与敌人接触时由同一逻辑检查状态：护盾生效或正在冲刺则存活；否则暂停游戏并显示结束界面。收集物与冲刺道具通过父子类继承共用结构，保留各自效果。One shared collision check handles player-enemy contact: an active shield or dash keeps the player alive; otherwise the game pauses and shows the game-over screen. Pickup variants share parent-child structures while keeping their distinct effects.

MOBILE / ONE-FINGER PLAY

手指可在屏幕任意位置滑动，不必精确点按角色。界面减少遮挡，并把按钮放大、排列为四键网格，适应较小屏幕和单手操作。Swipe anywhere on screen without targeting the character. A reduced overlay and larger four-button grid adapt the interface to smaller screens and one-finger play.

PC / PLATFORM PROMPTS

开始界面与 HUD 会识别运行平台，显示相应的操作提示和界面布局。The start screen and HUD detect the platform and show the corresponding control prompts and interface layout.

存档路线与成绩记录Saved Routes & High Scores

重玩 / 进度REPLAY / PROGRESS
SEED-BASED SAVE

保存同一条赛道Replay the same route

关卡存档保存随机流种子。读取时以种子重新建立随机流，重现相同的平台、敌人和收集物排列；封装随机调用并等待数据加载完成后再生成对象，保持顺序稳定。A run save stores the random seed. Loading creates a fresh stream from that seed to recreate the same platforms, enemies and pickups. Centralized random calls and a load-ready gate keep generation order stable.

SEED→RANDOM STREAM→REPLAYABLE RUN
JSON HIGH SCORE

可读的成绩存档Readable score records

结束时玩家可选择保存成绩；只有新成绩更高时才替换记录。JSON 文件保存玩家输入的名字、游戏时长与最终分数，格式可直接阅读。Players can save a run at game over; the record updates only when the new score is higher. The human-readable JSON file stores the entered name, run duration and final score.

CLASS HIERARCHY

父类定义共用行为，子类切换金币分值与道具效果。Shared parent behavior; child classes vary coin values and pickup effects.

COMPOSITE

平台负责带动尖刺球与收集物。Platforms carry their spiked balls and pickups.

PROTOTYPE UI

主菜单、暂停和结束界面复用按钮模板。One button template is reused across menu, pause and game-over screens.

LOAD GATE

随机流初始化完成后才允许生成对象。Object generation waits until the random stream is ready.
